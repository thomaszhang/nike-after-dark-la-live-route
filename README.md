# Nike After Dark LA 2026 Live Course

A phone-ready live-location map using the official 834-point Nike After Dark Tour Los Angeles course.

- Live GPS position remains in the browser and is never uploaded.
- Shows nearest course point, progress, remaining distance, and off-course distance.
- Installable to an iPhone Home Screen.
- Official course source: https://www.afterdarktour.nike.com/en/la

The official site advertises 13.1 miles; its current source polyline measures approximately 13.32 miles. Race-day closures and course changes can differ, so re-check Nike's page before the event.
